# 作品 A 标记网页验证

A 标记保存时保留当前作品卡片、封面、原按钮及完整祖先链。等待态使用忙碌属性并拦截重复提交，按钮仍可保持原生焦点；确认后同一按钮可继续移除标记。当前失败在原卡片内持续显示原因和重试入口，保留最近确认状态；旧失败不会覆盖新搜索错误或抢走草稿焦点。

## 保存失败后的恢复

失败原因使用纯文本和消息警报属性，位于卡片正文之后，不打开阻塞弹窗或重建列表。长原因按可用宽度换行，在有高度上限的区域中支持聚焦和原生键盘滚动；独立重试按钮不会打开播放页或预热媒体。

重试保留失败时明确的启用／移除意图，不根据后来状态反转。等待时保留原错误区、原因和重试按钮，通过忙碌属性及现有在途记录阻止重复提交；重复失败只更新原因，有效确认后清除。清除时若焦点仍在错误区内，则以 preventScroll 返回原标记按钮；没有后续视口手势时，再按实际顶栏和视口边界滚动必要距离，让按钮完整可见。等待期间后续滚轮、PageDown 等视口操作保持优先；后来聚焦的输入框、草稿及选区保持。重复 Enter、Space 或点击原重试按钮不会增加提交，也不会误取消正常显露。仅已有错误区的请求临时记录手势，结束时移除监听。新页面及退休的重试控件不能再提交旧操作，历史导航等待资料库时，迟到失败也不能向仍挂载的旧卡片发布提示。

## 标记与路径

真实服务的 A 标记会重命名本地目录，并更新数据库和内存路径。网页验证通过私有合成服务接收 POST，不调用真实标记接口或修改用户文件。

| 回包内容 | 客户端处理 |
| --- | --- |
| `localMarkers`、`directoryName`、`relativePath` | 合并到原记录、当前列表、已知资料库副本及当前详情。公开目录名可能已经去掉 `[A]`，不依靠显示名称推断标记。 |
| `videos`、`images`、`infos` | 按文件 ID 更新 `sourcePath`、`relativePath`；保留当前数组、文件对象和较新的成员、标题与进度。 |
| 收藏、评分、封面、标题及其他元数据 | 保留当前值，避免迟到的完整作品 DTO 回退其他操作。 |

普通列表的确认不重建网格。已在途的作品读取可获得标记和路径投影，按作品及文件 ID 克隆修补其 DTO；不会改写旧快照、总数或游标，也不会给紧凑 DTO 添加不完整媒体数组。记录在完成、失败或取消后退休，之后新发起的 GET 不继承旧投影。

## 筛选与请求归属

`localMarkedA` 筛选和精确 `[A]` 搜索涉及成员变化，确认后通过当前读取器从 offset 0 重读。实际前台读取包含缓存消费，在原有 finally 中退休；后台预取和索引不登记为前台读取。已在途的旧成员快照不能恢复刚取消标记的作品，后续页按新的服务器前缀继续读取。

刷新保留当前查询、排序和路由语义。片商读取刷新实际请求的目标与系列；搜索刷新保留原 push、replace、skipRoute 行为及未提交草稿，并使用新的请求归属。历史导航正在等待资料库时，迟到标记不能重启旧条件。

保存等待期间切入的 A 筛选或 `[A]` 搜索，若已成功读完，确认后也按当前条件重读一次，包括已有其他成员但尚未包含新标记作品的结果。列表归属只保留一个呈现记录，核对成功读取游标、原空态或直属卡片节点、导航、上下文及目标和实际地址；新的前台读取开始时清除它，成功渲染或追加后重新登记，读取失败和历史导航不继承旧归属。首批卡片同步登记，后续渐进批次不改变它。人物、番号、片商仅登记详情，索引和排行榜不登记。

有效确认后，搜索、人物、片商和收藏页的未消费预取缓存失效，包括已完成的空结果；`changed:false` 的有效回包也执行该步骤。已消费并交给前台的读取保持原请求归属，不因清缓存被取消。失败或无效回包保留缓存；清缓存本身不发起 GET，不取消新的草稿预取计时器。

## 对照与限制

保存 503 的同链对照中，旧实现产生一次真实浏览器警告对话框，关闭后没有常驻原因和重试入口；新实现不产生对话框，在原卡片内保留反馈。原输入框、卡片和按钮的完整祖先、草稿、反向选区及焦点保留，原生重试和重复按键只产生启用、重试两次模拟 POST，没有 GET 或其他写入。320×360 的 3858 字原因在 72px 区域内可用 Home／End 读到首尾，页面宽度保持 320px；重试为 50×44px 并通过中心命中。新增警报及键盘语义不等同于实测屏幕阅读器。

相同原生操作链中，保存前完成的 `[A]` 空预取在旧实现中被继续复用，已标记作品仍不显示；修正后确认本身不发 GET，随后 Enter 搜索恰好新增一次读取并显示作品及已激活按钮。确认保留当前输入、选区、焦点和完整祖先链；失败分支继续复用原空缓存。人物详情的旧缓存也通过实际导航、路径及下一次移除请求核对。

另一条相同操作链先提交并接受 `[A]` 空结果，再释放早先的保存确认：旧实现仍保留空列表，修正后恰好新增一次 offset 0 GET，显示新成员和已激活 A 状态。规范网址、输入框及完整祖先链、后续原始草稿、反向选区和焦点保持；只有所需的一次模拟标记 POST。

已有一条 A 结果的同链对照也确认：旧实现收到保存成功后仍只显示原成员；修正后恰好新增一次 offset 0 GET，当前结果和数量由一条更新为两条，两条均为已标记状态。网址、输入框完整祖先、后续原始草稿、反向选区及焦点保持，没有其他写入或确认；必要的成员刷新会替换作品卡片，不将其报告为卡片原位更新。

相同千卡操作链中，保存确认后的原卡片和封面由全部脱离变为全部保留，显式元素构造 340→0、图源赋值 16→0，35,200px 滚动不再跳到 335px。原生等待和确认后的失焦为 0；旧等待态禁用按钮时已有一次失焦。旧实现仅重新挂载前 24 张卡片，构造数不代表重建了一千张卡片；封面 HTTP 增量两者均为 0，不据此宣称网络收益。

320×360 的等待态忙碌属性、实际样式、原生连续操作与中心命中均复核。当前样本按钮为 32×32px；标记 API 增量恰好为启用、移除两次模拟 POST，没有额外 GET、其他写入或确认。结果来自合成 API、SVG 封面与私有 Chromium，不证明真实目录重命名、正式库性能或媒体播放。

30 条合成列表的 320×360 原生键盘链另证明：重试成功后旧实现虽返回原 A 焦点，按钮却完整落在视口上方；修正后从重试或原因区返回时，原按钮完整位于实际顶栏下且可命中。七种分支保留首批 12 张原卡、封面、输入框及完整祖先，均仅有两次明确启用 POST，没有列表重读；新的输入保留草稿与反向选区，滚轮保留滚动位置，PageDown 分支允许浏览器在错误区移除后保持原可见卡片的锚点。重复原生按键和再次点击同一重试按钮仍可正常显露；可见性以实际完整矩形与命中核对；鼠标悬停预热沿用现有流程。
